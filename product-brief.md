# Content library

Plugin identity:
- displayName: Content library
- description: Import, search and apply a CSV content library to selected text layers.

Original user prompt:
REcreate this plugin for figma, i've uploaded the files

Usage:
Import a CSV with category, subcategory, key, heading, body, ctas and source_file headers. Browse source groups, search, filter categories and content types, choose copy, then apply after selection preview. The library is stored on this device. Only directly selected editable text layers are modified, with font loading and stale-selection checks. Recreated from the uploaded code.ts and ui.html without external services or credentials.
